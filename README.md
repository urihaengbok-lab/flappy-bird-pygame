# Flappy Bird (Python, pygame)

이 프로젝트는 Python과 pygame을 사용하여 만든 간단한 Flappy Bird 게임입니다.

> **본 프로젝트는 Helpy chat과 GitHub MCP를 활용하여 자동 생성되었습니다.**

## 실행 방법

1. Python이 설치되어 있어야 합니다.
2. pygame 라이브러리를 설치하세요:
   ```bash
   pip install pygame
   ```
3. `flappy_bird.py` 파일을 실행하세요:
   ```bash
   python flappy_bird.py
   ```

## 주요 파일
- `flappy_bird.py`: 게임의 메인 코드

## 제작 도구
- Helpy chat (AI assistant)
- GitHub MCP (자동화 업로드)

## GitHub Pages로 배포하는 방법

> **참고:** 이 프로젝트는 Python 기반이므로 GitHub Pages(정적 웹사이트 호스팅)로 직접 실행 배포는 불가능합니다. 하지만, 웹 기반(HTML/JS) 게임이라면 아래와 같이 배포할 수 있습니다.

1. 웹 프로젝트라면 `index.html` 파일을 레포지토리에 추가하세요.
2. 레포지토리의 Settings > Pages 메뉴로 이동하세요.
3. "Source"에서 배포할 브랜치(main 등)와 폴더(root 또는 `/docs`)를 선택하세요.
4. 저장하면, `https://<유저명>.github.io/<레포명>/` 주소로 접속할 수 있습니다.

**이 Python 프로젝트는 로컬에서 실행해야 합니다.**
